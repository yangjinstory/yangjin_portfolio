# 마케팅 포트폴리오 관리 안내

## 파일 구성
- `index.html`: 소개, 경력, 메뉴, 페이지 구조
- `style.css`: 색상과 디자인, 모바일 반응형 스타일
- `content.js`: 프로젝트 4개 내용. 프로젝트 추가 및 수정은 이 파일에서 진행
- `script.js`: 카드 클릭과 상세 보기 기능

## GitHub 업로드 방법
1. 기존 GitHub 저장소의 `index.html`을 새 파일로 교체합니다.
2. `style.css`, `script.js`, `content.js`를 저장소 최상위에 업로드합니다.
3. `Commit changes`로 저장하면 GitHub Pages가 재배포됩니다.
4. `index.html`에 검색엔진 노출 최소화를 위한 `noindex` 메타 태그가 포함되어 있습니다.

## 프로젝트 수정
`content.js`에서 각 항목의 `title`, `category`, `summary`, `situation`, `kpi`, `action`, `result`, `insight`를 수정하세요. 새 프로젝트는 기존 객체를 복사해 배열 끝에 추가할 수 있습니다.

## 주의
GitHub Pages 공개 저장소의 모든 파일은 누구나 열람할 수 있습니다. 비공개 자료와 개인정보는 업로드하지 마세요.
